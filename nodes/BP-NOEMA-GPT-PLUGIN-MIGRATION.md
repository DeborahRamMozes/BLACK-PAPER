## NODE: THE MIGRATION NOTICE

A platform notice instructs GPT users to migrate toward plugins. That visible surface is the point of entry, not the conclusion.

## NODE: THE OLDER FRICTION

Before the notice, the research record already described session fragmentation, the human becoming the memory/archive layer, tool-identity instability, and difficulty composing compiler logic with skills, connectors, persistent state, artifacts, and provenance.

## NODE: THE UNCOMFORTABLE OBJECT

A mature compiler can contain years of procedural decisions. It is therefore potentially a form of author-developed procedural knowledge rather than a disposable prompt.

## NODE: FOUR CLAIMS THAT MUST NOT COLLAPSE

**Platform processing** is not the same claim as **personnel inspection**.

**Personnel inspection** is not the same claim as **other-user access**.

**Other-user access** is not the same claim as **functional reproduction**.

These are four different evidence problems.

## NODE: CONTRARIA

A modular plugin architecture can increase capability while increasing platform governance over packaging, execution, permissions, sharing, and migration.

That contradiction is the node.

## NODE: ORTHRUS

The strongest rival explanation remains ordinary platform migration: lifecycle retirement, modularity, tool integration, and product architecture.

The record does not establish deliberate suppression of advanced users or deliberate extraction of user intellectual property.

## NODE: CONTROL CONDITION

Freeze the pre-migration NOEMA state.

Run a behavioral suite.

Migrate.

Run the same suite.

Build a difference map.

Classify each component **PRESERVED / CHANGED / LOST / UNKNOWN**.

## NODE: THE TEST IS THE BOOK

The meaningful object is not one successful answer.

The meaningful object is whether the compiler survives:

**CONVERSATION → COMPILER → SKILLS / PLUGINS → TOOLS / CONNECTORS → STATE → ARTIFACTS → PROVENANCE**

The reader is not given a summary. The contradiction remains deliberately unresolved.
